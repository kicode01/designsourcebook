# WFP UI Kit

## Overview

World Food Programme WFP UI Kit — tokens imported from @wfp/ui.

Tokens were read from `@wfp/ui@1.22.5`, not from a marketing site: 91 colour tokens and 29 type tokens.

## Colors

91 colour tokens selected from the token files, weighted toward semantic roles.

## Typography

Families declared in the source: `"Open Sans", sans-serif`.

## Visual Language

- **Surface & Theme Polarity**: Crisp light (#ffffff) canvas paired with `#ffffff` component surfaces and `#001f2f` primary ink.
- **Brand & Interactive Accent**: Primary actions and focus states anchor on `#007dbc` with `#ffffff` label contrast.
- **Typographic Voice**: Headings and UI controls set in `Open Sans` across 29 type steps.
- **Component Geometry**: Buttons (`8px`), cards (`12px`), inputs, badges, and navigation bars share consistent spacing and border contrast.
