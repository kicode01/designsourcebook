# Kendo UI

## Overview

**Kendo UI** is a light-first design system anchored on `#ffffff` canvas surfaces with `#0b0b0c` primary ink (19.7:1 contrast) and `#ff6358` brand accent.

Typography centers cleanly on `(Arial` (20px display down to 16px body), unified by `0.25rem` base corner radius and subtle shadow elevation.

Maintained by **Progress Telerik**. Source: published token package (https://github.com/telerik/kendo-themes/tree/master/packages/default), package `@progress/kendo-theme-default`. Inventory: **42** colors, **31** typography steps, and **49** documented components (Apache-2.0 license).

## Colors

- **Canvas (`canvas`)**: `#ffffff` — base application backdrop (light theme).
- **Surface (`surface`)**: `#ffffff` — elevated cards, popovers, and panels (separated via `1px` border lines).
- **Primary Ink (`text`)**: `#0b0b0c` — body copy and primary headings (19.7:1 on canvas).
- **Muted Ink (`muted`)**: `#0b0b0c` — secondary captions, placeholders, and helper labels.
- **Brand Accent (`brand`)**: `#ff6358` (2.9:1 vs canvas; pair with `#f7f7f8` foreground ink for 2.7:1 contrast).
- **Structural Border (`border`)**: `color-mix(in srgb, #0b0b0c 14%, transparent)` — divider rules, input strokes, and card outlines.
- **Brand & Accent Scale**: `primary` (`#ff6358`), `tertiary` (`#03a9f4`), `series` (`#ff6358`), `kendo-accent-icon-color` (`#8B7CF6`), `kendo-color-preview-no-color-text` (`#f31700`), `kendo-editor-selectednode-outline-color` (`#88ccff`).
- **Neutral Ramp**: `app-surface` (`#ffffff`), `subtle` (`#666666`), `surface` (`#fafafa`), `pretty-value` (`#f5f5f5`), `secondary` (`#666666`), `inverse` (`#3d3d3d`).
- **Semantic States**: success: `success` (`#37b400`) · danger: `error` (`#f31700`) · warning: `warning` (`#ffc000`) · info: `info` (`#0058e9`).

## Typography

- **Primary / Display Voice**: `"(Arial", Verdana, Tahoma, "Trebuchet MS", Helvetica, Impact, "Gill Sans)"` (top step `kendo-font-size-xl`: 1.25rem, weight 600).
- **Body & UI Controls**: `"(Arial", Verdana, Tahoma, "Trebuchet MS", Helvetica, Impact, "Gill Sans)"` (`kendo-font-size-lg`: 1rem, weight 400).
- **Monospace / Technical Labels**: `"(SFMono-Regular", Menlo, Monaco, Consolas, "Roboto Mono", "Ubuntu Mono", "Lucida Console", "Courier New", "monospace)"` (`kendo-font-family-monospace`: 16px).
- **Scale Steps (31)**: `kendo-font-size-xl` (1.25rem), `kendo-pivotgrid-configurator-header-font-size` (18px), `kendo-font-size-lg` (1rem), `kendo-font-family-sans` (16px), `kendo-font-family-serif` (16px), `kendo-font-family-sans-serif` (16px), `kendo-font-family-monospace` (16px), `kendo-spreadsheet-action-bar-font-family` (16px).

## Layout

- **Grid & Control Spacing**: Derived from 49 component tokens with documented paddings: `0`, `8px 12px`, `2px`, `6px 12px`, `12px 14px`.
- **Hierarchy**: Group controls cleanly within `#ffffff` cards; separate sibling sections using `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines rather than oversized whitespace.

## Elevation

- **Layered Shadow Model**: Uses documented shadows (`0 4px 6px rgba(0, 0, 0, 0.06), 0 4px 16px rgba(0, 0, 0, 0.12)`, `0 8px 10px rgba(0, 0, 0, 0.12), 0 4px 16px rgba(0, 0, 0, 0.12)`) paired with `color-mix(in srgb, #0b0b0c 14%, transparent)` borders for elevated overlays.
- **Interactive Lift**: Reserve higher surface brightness or focus outlines anchored on `#ff6358` for keyboard focus and active selection states.

## Shapes

- **Base Corner Geometry**: `0.25rem` (Buttons `0.25rem` · Inputs `0.25rem` · Badges `0.25rem`).
- **Nested Concentricity**: Keep nested pills/badges pill-shaped (`999px`) or tighter than their parent `0.25rem` container.
- **Iconography & SVGs**: Inline System SVGs on a `20x20` grid (outline, stroke `1.75px`, `round` caps).

## Do's and Don'ts

### Do
- Anchor base views on `#ffffff` (light) with `#0b0b0c` primary text and `#0b0b0c` secondary labels.
- Use `#ff6358` with `#f7f7f8` text (2.7:1) for primary CTAs, active tabs, and focus outlines.
- Pair `(Arial` headings with `(Arial` body copy using documented weights and scale steps.
- Apply `0.25rem` base geometry across inputs and buttons (0.25rem on outer containers).
- Separate containers via `#ffffff` surface shifts and `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines cleanly.

### Don't
- Do not invert the base canvas out of light polarity without explicitly switching component text tokens.
- Do not place low-contrast muted ink or raw white text on light accents without verifying >= 4.5:1 WCAG AA contrast.
- Do not invent arbitrary brand colors, unverified fonts, or synthetic heavy shadows outside the palette above.
- Do not mix conflicting corner radii that clash with the system's `0.25rem` baseline.
- Do not truncate or drop border contrast on `input` fields and secondary buttons.
