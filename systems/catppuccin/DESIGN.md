# Catppuccin

## Overview

**Catppuccin** is a light-first design system anchored on `#eff1f5` canvas surfaces with `#0b0b0c` primary ink (17.4:1 contrast) and `#c6a0f6` brand accent.

Typography centers cleanly on `System UI` (large display down to 14px body), unified by `8px` base corner radius and hairline `1px` structural borders.

Source: published token package (https://github.com/catppuccin/palette#readme), package `@catppuccin/palette`. Inventory: **91** colors, **0** typography steps, and **8** documented components (MIT license).

- **Canvas (`canvas`)**: `#eff1f5` — base application backdrop (light theme).
- **Surface (`surface`)**: `#eff1f5` — elevated cards, popovers, and panels (separated via `1px` border lines).

## Do's and Don'ts

### Do
- Anchor base views on `#eff1f5` (light) with `#0b0b0c` primary text and `#0b0b0c` secondary labels.
- Use `#c6a0f6` with `#0b0b0c` text (9.1:1) for primary CTAs, active tabs, and focus outlines.
- Pair `System UI` headings with `System UI` body copy using documented weights and scale steps.
- Apply `8px` base geometry across inputs and buttons (8px on outer containers).
- Separate containers via `#eff1f5` surface shifts and `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines cleanly.

### Don't
- Do not invert the base canvas out of light polarity without explicitly switching component text tokens.
- Do not place low-contrast muted ink or raw white text on light accents without verifying >= 4.5:1 WCAG AA contrast.
- Do not invent arbitrary brand colors, unverified fonts, or synthetic heavy shadows outside the palette above.
- Do not mix conflicting corner radii that clash with the system's `8px` baseline.
- Do not truncate or drop border contrast on `input` fields and secondary buttons.
