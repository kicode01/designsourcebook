# ByteDance Arco Design

## Overview

ByteDance Arco Design — tokens read from https://github.com/arco-design/arco-design.

Tokens were read from the project's own repository, not from a marketing site: 23 colour tokens and 9 type tokens.

## Colors

23 colour tokens selected from the token files, weighted toward semantic roles.

## Typography

No resolvable type tokens were extracted. The type scale is omitted rather than invented.

## Visual Language

- **Surface & Theme Polarity**: Crisp light (#FFF) canvas paired with `#FFF` component surfaces and `#0b0b0c` primary ink.
- **Brand & Interactive Accent**: Primary actions and focus states anchor on `#ff7d00` with `#0b0b0c` label contrast.
- **Typographic Voice**: Headings and UI controls set in `NunitoSans-Bold` across 37 type steps.
- **Component Geometry**: Buttons (`4px`), cards (`8px`), inputs, badges, and navigation bars share consistent spacing and border contrast.
