# Vuetify

## Overview

**Vuetify** is a light-first design system anchored on `#FFFFFF` canvas surfaces with `#0b0b0c` primary ink (19.7:1 contrast) and `#FF8A80` brand accent.

Typography centers cleanly on `System UI` (57px display down to 16px body), unified by `4px` base corner radius and subtle shadow elevation.

Source: published token package (https://vuetifyjs.com), package `vuetify`. Inventory: **90** colors, **117** typography steps, and **31** documented components (MIT license).

## Colors

- **Canvas (`canvas`)**: `#FFFFFF` — base application backdrop (light theme).
- **Surface (`surface`)**: `#EEEEEE` — elevated cards, popovers, and panels.
- **Primary Ink (`text`)**: `#0b0b0c` — body copy and primary headings (19.7:1 on canvas).
- **Muted Ink (`muted`)**: `#0b0b0c` — secondary captions, placeholders, and helper labels.
- **Brand Accent (`brand`)**: `#FF8A80` (2.3:1 vs canvas; pair with `#0b0b0c` foreground ink for 8.6:1 contrast).
- **Structural Border (`border`)**: `color-mix(in srgb, #0b0b0c 14%, transparent)` — divider rules, input strokes, and card outlines.
- **Brand & Accent Scale**: `colors-primary` (`#1867C0`), `colors-primary-darken-1` (`#1F5592`), `colors-secondary` (`#48A9A6`), `colors-secondary-darken-1` (`#018786`), `primary` (`#FF8A80`), `primary-darken-1` (`#1F5592`).
- **Neutral Ramp**: `colors-background` (`#FFFFFF`), `colors-surface` (`#FFFFFF`), `colors-surface-bright` (`#FFFFFF`), `colors-surface-light` (`#EEEEEE`), `colors-surface-variant` (`#424242`), `colors-on-surface-variant` (`#EEEEEE`).
- **Semantic States**: success: `colors-success` (`#4CAF50`) · danger: `colors-error` (`#B00020`) · warning: `colors-warning` (`#FB8C00`) · info: `colors-info` (`#2196F3`).

## Layout

- **Grid & Control Spacing**: Derived from 31 component tokens with documented paddings: `0`, `8px 12px`, `2px`, `6px 12px`, `10px 14px`.
- **Hierarchy**: Group controls cleanly within `#EEEEEE` cards; separate sibling sections using `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines rather than oversized whitespace.

## Elevation

- **Layered Shadow Model**: Uses documented shadows (`0 0 0 0 rgba(,.3),0 0 0 0 rgba(,.15)`) paired with `color-mix(in srgb, #0b0b0c 14%, transparent)` borders for elevated overlays.
- **Interactive Lift**: Reserve higher surface brightness or focus outlines anchored on `#FF8A80` for keyboard focus and active selection states.

## Shapes

## Do's and Don'ts

### Do
- Anchor base views on `#FFFFFF` (light) with `#0b0b0c` primary text and `#0b0b0c` secondary labels.
- Use `#FF8A80` with `#0b0b0c` text (8.6:1) for primary CTAs, active tabs, and focus outlines.
- Pair `System UI` headings with `System UI` body copy using documented weights and scale steps.
- Apply `4px` base geometry across inputs and buttons (4px on outer containers).
- Separate containers via `#EEEEEE` surface shifts and `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines cleanly.

### Don't
- Do not invert the base canvas out of light polarity without explicitly switching component text tokens.
- Do not place low-contrast muted ink or raw white text on light accents without verifying >= 4.5:1 WCAG AA contrast.
- Do not invent arbitrary brand colors, unverified fonts, or synthetic heavy shadows outside the palette above.
- Do not mix conflicting corner radii that clash with the system's `4px` baseline.
- Do not truncate or drop border contrast on `v-otp-input` fields and secondary buttons.
