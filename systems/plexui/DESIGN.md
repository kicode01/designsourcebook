# Plex UI

## Overview

**Plex UI** is a light-first design system anchored on `#fff` canvas surfaces with `#0b0b0c` primary ink (19.7:1 contrast) and `#0285ff` brand accent.

Typography centers cleanly on `Inter Variable` (34px display down to 17px body), unified by `8px` base corner radius and stepped `#fff` -> `#f9f9f9` surface layering.

Source: published token package (https://plexui.com), package `@plexui/styles`. Inventory: **91** colors, **83** typography steps, and **8** documented components (MIT license).

## Colors

- **Canvas (`canvas`)**: `#fff` — base application backdrop (light theme).
- **Surface (`surface`)**: `#f9f9f9` — elevated cards, popovers, and panels.
- **Primary Ink (`text`)**: `#0b0b0c` — body copy and primary headings (19.7:1 on canvas).
- **Muted Ink (`muted`)**: `#0b0b0c` — secondary captions, placeholders, and helper labels.
- **Brand Accent (`brand`)**: `#0285ff` (3.6:1 vs canvas; pair with `#f7f7f8` foreground ink for 3.4:1 contrast).
- **Structural Border (`border`)**: `color-mix(in srgb, #0b0b0c 14%, transparent)` — divider rules, input strokes, and card outlines.
- **Brand & Accent Scale**: `color-accent` (`#0285ff`), `codeblock-syntax-1` (`#c0660d`), `pink-75` (`#ffd4e8`), `pink-100` (`#ffbada`), `pink-200` (`#ffa3ce`), `pink-300` (`#ff8cc1`).
- **Neutral Ramp**: `codeblock-background-color` (`#f9f9f9`), `color-picker-add-background` (`#d9d9d9`), `color-picker-selection-color` (`#fff`), `gray-500` (`#5d5d5d`), `white` (`#ffffff`), `black` (`#000000`).
- **Semantic States**: success: `green-50` (`#d9f4e4`) · danger: `red-50` (`#ffd9d9`) · warning: `orange-50` (`#ffe7d9`).

## Typography

- **Primary / Display Voice**: `"Inter Variable", Inter, ui-sans-serif, system-ui, "Segoe UI", "Noto Sans", Helvetica, Arial, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", sans-serif` (top step `toolbar-large-title-font-size`: 34px, weight 600).
- **Body & UI Controls**: `"Inter Variable", Inter, ui-sans-serif, system-ui, "Segoe UI", "Noto Sans", Helvetica, Arial, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", sans-serif` (`floating-input-font-size`: 17px, weight 400).
- **Monospace / Technical Labels**: `"Geist Mono Variable", "Geist Mono", ui-monospace, Menlo, Consolas, "Liberation Mono", "DejaVu Sans Mono", "Courier New", monospace` (`font-mono`: 16px).
- **Scale Steps (83)**: `toolbar-large-title-font-size` (34px), `h1` (1.75em), `h2` (1.5em), `toolbar-medium-title-font-size` (22px), `page-title-font-size` (20px), `h3` (1.25em), `floating-input-font-size` (17px), `toolbar-label-font-size` (17px).

## Layout

- **Grid & Control Spacing**: Derived from 8 component tokens with documented paddings: `8px 12px`, `2px`, `6px 12px`, `12px 14px`, `10px 14px`.
- **Hierarchy**: Group controls cleanly within `#f9f9f9` cards; separate sibling sections using `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines rather than oversized whitespace.

## Elevation

- **Surface & Stroke Elevation**: Relies on crisp tonal contrast (`#fff` -> `#f9f9f9`) and `1px solid color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines instead of heavy drop shadows.
- **Interactive Lift**: Reserve higher surface brightness or focus outlines anchored on `#0285ff` for keyboard focus and active selection states.

## Shapes

- **Base Corner Geometry**: `8px`.
- **Nested Concentricity**: Keep nested pills/badges pill-shaped (`999px`) or tighter than their parent `8px` container.
- **Iconography & SVGs**: Inline System SVGs on a `20x20` grid (outline, stroke `1.75px`, `round` caps).

## Do's and Don'ts

### Do
- Anchor base views on `#fff` (light) with `#0b0b0c` primary text and `#0b0b0c` secondary labels.
- Use `#0285ff` with `#f7f7f8` text (3.4:1) for primary CTAs, active tabs, and focus outlines.
- Pair `Inter Variable` headings with `Inter Variable` body copy using documented weights and scale steps.
- Apply `8px` base geometry across inputs and buttons (8px on outer containers).
- Separate containers via `#f9f9f9` surface shifts and `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines cleanly.

### Don't
- Do not invert the base canvas out of light polarity without explicitly switching component text tokens.
- Do not place low-contrast muted ink or raw white text on light accents without verifying >= 4.5:1 WCAG AA contrast.
- Do not invent arbitrary brand colors, unverified fonts, or synthetic heavy shadows outside the palette above.
- Do not mix conflicting corner radii that clash with the system's `8px` baseline.
- Do not truncate or drop border contrast on `input` fields and secondary buttons.
