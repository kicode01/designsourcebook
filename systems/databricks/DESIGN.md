# Databricks

## Overview

**Databricks** is a light-first design system anchored on `#ffffff` canvas surfaces with `#8b5a0e` primary ink (5.9:1 contrast) and `#9e102c` brand accent.

Typography centers cleanly on `DM Sans` (48px display down to 13px body), unified by `4px` base corner radius and subtle shadow elevation.

Source: published token package, package `@databricks/design-system`. Inventory: **91** colors, **40** typography steps, and **73** documented components (ISC license).

## Colors

- **Canvas (`canvas`)**: `#ffffff` — base application backdrop (light theme).
- **Surface (`surface`)**: `#f0f8ff` — elevated cards, popovers, and panels.
- **Primary Ink (`text`)**: `#8b5a0e` — body copy and primary headings (5.9:1 on canvas).
- **Muted Ink (`muted`)**: `#8b5a0e` — secondary captions, placeholders, and helper labels.
- **Brand Accent (`brand`)**: `#9e102c` (8.2:1 vs canvas; pair with `#f7f7f8` foreground ink for 7.6:1 contrast).
- **Structural Border (`border`)**: `#f5f5f5` — divider rules, input strokes, and card outlines.
- **Brand & Accent Scale**: `db-accent-surface-strong` (`#2272b4`), `db-accent-border` (`#2272b4`), `db-color-tag-text-lemon` (`#4F3422`), `db-color-action-default-border-press` (`#04355d`), `db-color-action-primary-background-press` (`#04355d`), `db-color-action-tertiary-text-hover` (`#0e538b`).
- **Neutral Ramp**: `db-slider-range-surface-disabled` (`#e8ecf0`), `db-banner-warning-text-active` (`#11171c`), `db-surface-base` (`#ffffff`), `db-text-subtle` (`#6f6f6f`), `db-border-subtle` (`#f5f5f5`), `db-tree-scroll-to-top-surface` (`#f0f8ff`).
- **Semantic States**: success: `db-positive-surface-active` (`#093919`) · danger: `db-alert-border-error` (`#fbd0d8`) · warning: `db-banner-warning-surface` (`#facb66`) · info: `db-banner-info-surface` (`#8a63bf`).

## Typography

- **Primary / Display Voice**: `"DM Sans", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif` (top step `db-font-size-4xl`: 3rem, weight 600).
- **Body & UI Controls**: `"DM Sans", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif` (`db-font-size-base`: 0.8125rem, weight 400).
- **Monospace / Technical Labels**: `monospace` (`db-typography-code-font-family`: 16px).
- **Scale Steps (40)**: `db-font-size-4xl` (3rem), `db-font-size-3xl` (2.5rem), `db-typography-h1-font-size` (2.25rem), `h1` (36px, w600), `db-font-size-2xl` (2rem), `db-typography-h2-font-size` (1.75rem), `h2` (28px, w600), `db-typography-h3-font-size` (1.4375rem).

## Layout

- **Grid & Control Spacing**: Derived from 73 component tokens with documented paddings: `0 16px`, `0`, `5px 8px`, `16px 16px`, `6px 8px`.
- **Hierarchy**: Group controls cleanly within `#f0f8ff` cards; separate sibling sections using `#f5f5f5` hairlines rather than oversized whitespace.

## Elevation

- **Layered Shadow Model**: Uses documented shadows (`0 2px 0 rgba(0, 0, 0, 0.015)`, `0 3px 6px -4px rgba(0, 0, 0, 0.12), 0 6px 16px 0 rgba(0, 0, 0, 0.08), 0 9px 28px 8px rgba(0, 0, 0, 0.05)`) paired with `#f5f5f5` borders for elevated overlays.
- **Interactive Lift**: Reserve higher surface brightness or focus outlines anchored on `#9e102c` for keyboard focus and active selection states.

## Shapes

- **Base Corner Geometry**: `4px` (Buttons `4px` · Inputs `4px` · Badges `4px`).
- **Nested Concentricity**: Keep nested pills/badges pill-shaped (`999px`) or tighter than their parent `4px` container.
- **Iconography & SVGs**: Ant Design Icons (`@ant-design/icons`) on a `16x16` grid (outline, stroke `1.5px`, `round` caps).

## Do's and Don'ts

### Do
- Anchor base views on `#ffffff` (light) with `#8b5a0e` primary text and `#8b5a0e` secondary labels.
- Use `#9e102c` with `#f7f7f8` text (7.6:1) for primary CTAs, active tabs, and focus outlines.
- Pair `DM Sans` headings with `DM Sans` body copy using documented weights and scale steps.
- Apply `4px` base geometry across inputs and buttons (4px on outer containers).
- Separate containers via `#f0f8ff` surface shifts and `#f5f5f5` hairlines cleanly.

### Don't
- Do not invert the base canvas out of light polarity without explicitly switching component text tokens.
- Do not place low-contrast muted ink or raw white text on light accents without verifying >= 4.5:1 WCAG AA contrast.
- Do not invent arbitrary brand colors, unverified fonts, or synthetic heavy shadows outside the palette above.
- Do not mix conflicting corner radii that clash with the system's `4px` baseline.
- Do not truncate or drop border contrast on `du-bois-light-input` fields and secondary buttons.
