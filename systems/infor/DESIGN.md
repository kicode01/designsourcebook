# Infor Design System

## Overview

**Infor Design System** is a light-first design system anchored on `#f0f0f0` canvas surfaces with `#0b0b0c` primary ink (17.3:1 contrast) and `#69b5dd` brand accent.

Typography centers cleanly on `System UI` (35px display down to 16px body), unified by `2px` base corner radius and subtle shadow elevation.

Maintained by **Infor**. Source: published token package (https://oxford.awsdev.infor.com/infor-design/enterprise), package `ids-enterprise`. Inventory: **91** colors, **9** typography steps, and **40** documented components (Apache-2.0 license).

## Colors

- **Canvas (`canvas`)**: `#f0f0f0` — base application backdrop (light theme).
- **Surface (`surface`)**: `#f0f0f0` — elevated cards, popovers, and panels (separated via `1px` border lines).
- **Primary Ink (`text`)**: `#0b0b0c` — body copy and primary headings (17.3:1 on canvas).
- **Muted Ink (`muted`)**: `#0b0b0c` — secondary captions, placeholders, and helper labels.
- **Brand Accent (`brand`)**: `#69b5dd` (2.0:1 vs canvas; pair with `#0b0b0c` foreground ink for 8.7:1 contrast).
- **Structural Border (`border`)**: `color-mix(in srgb, #0b0b0c 14%, transparent)` — divider rules, input strokes, and card outlines.
- **Brand & Accent Scale**: `fileupload-completed-border-color` (`#225800`), `button-primary-disabled-color-gen-ai` (`#C2A1F1`), `button-primary-disabled-hover-color-gen-ai` (`#C2A1F1`), `button-secondary-border-color-gen-ai` (`#C2A1F1`), `button-secondary-color-gen-ai` (`#C2A1F1`), `button-secondary-hover-color-gen-ai` (`#C2A1F1`).
- **Neutral Ramp**: `button-icon-disabled-color` (`rgba(0, 0, 0, 1)`), `button-tertiary-hover-background-color-gen-ai` (`#F5F5F5`), `button-gen-ai-icon-disabled-color` (`#fff`), `ids-color-brand-primary-contrast` (`#ffffff`), `ids-color-brand-secondary-lighter` (`#d8d8d8`), `ids-color-brand-secondary-base` (`#bdbdbd`).
- **Semantic States**: success: `ids-color-status-success` (`#80ce4d`) · danger: `error-color` (`#b94e4a`) · warning: `ids-color-status-warning` (`#ff9426`) · info: `ids-color-status-info` (`#2578a9`).

## Typography

- **Primary / Display Voice**: `system-ui` (top step `h2`: 2.2rem, weight 600).
- **Body & UI Controls**: `system-ui` (`body`: 1rem, weight 400).
- **Scale Steps (9)**: `h2` (2.2rem), `h3` (2rem), `empty-title` (1.8rem), `listview-heading` (1.6rem, w600), `listview-subheading` (1.6rem), `section-title` (20px), `body` (1rem), `title` (16px, w600).

## Layout

- **Grid & Control Spacing**: Derived from 40 component tokens with documented paddings: `0 10px`, `0`, `0 32px`, `10px 30px`, `10px 20px`.
- **Hierarchy**: Group controls cleanly within `#f0f0f0` cards; separate sibling sections using `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines rather than oversized whitespace.

## Elevation

- **Layered Shadow Model**: Uses documented shadows (`0 0 4px 0 #E0E0E1`, `0 0 4px rgba(0, 0, 0, 0.15)`) paired with `color-mix(in srgb, #0b0b0c 14%, transparent)` borders for elevated overlays.
- **Interactive Lift**: Reserve higher surface brightness or focus outlines anchored on `#69b5dd` for keyboard focus and active selection states.

## Shapes

- **Base Corner Geometry**: `2px` (Buttons `2px` · Cards `2px` · Badges `12px`).
- **Nested Concentricity**: Keep nested pills/badges pill-shaped (`999px`) or tighter than their parent `2px` container.
- **Iconography & SVGs**: Inline System SVGs on a `20x20` grid (outline, stroke `1.75px`, `round` caps).

## Do's and Don'ts

### Do
- Anchor base views on `#f0f0f0` (light) with `#0b0b0c` primary text and `#0b0b0c` secondary labels.
- Use `#69b5dd` with `#0b0b0c` text (8.7:1) for primary CTAs, active tabs, and focus outlines.
- Pair `System UI` headings with `System UI` body copy using documented weights and scale steps.
- Apply `2px` base geometry across inputs and buttons (2px on outer containers).
- Separate containers via `#f0f0f0` surface shifts and `color-mix(in srgb, #0b0b0c 14%, transparent)` hairlines cleanly.

### Don't
- Do not invert the base canvas out of light polarity without explicitly switching component text tokens.
- Do not place low-contrast muted ink or raw white text on light accents without verifying >= 4.5:1 WCAG AA contrast.
- Do not invent arbitrary brand colors, unverified fonts, or synthetic heavy shadows outside the palette above.
- Do not mix conflicting corner radii that clash with the system's `2px` baseline.
- Do not truncate or drop border contrast on `input-style` fields and secondary buttons.
